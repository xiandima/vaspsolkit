# 用户手册与操作体验改版

## 已确认的方向

保留 Sphinx、MyST、现有主题和 GitHub Pages。采用左侧任务导航、正文操作步骤和页内目录，补充预期输出与故障入口。同步修复审查中可复现的 CLI 使用问题，并安排独立验收。

## 用户与范围

主要读者是通过 SSH 使用 VASP/VASPsol 的计算用户。首次使用者需要从输入目录走到五点结果；已有任务的用户需要迅速找到继续、检查、恢复和结果解释。README 保留安装与入口，详细操作以在线手册为准。

不更换计算模型，不引入新的任务后台，不提交真实计算，不移动原始数据。保留唯一中性扫描点、默认 CHGCAR 初猜、不默认读取 WAVECAR、未知状态阻止重复提交等约束。

## 页面与内容

- 首页直接给出首次使用、继续计算、处理异常和查看结果的入口，不做营销式首页。
- 左侧按开始使用、运行计算、读取结果、查询参考分组；长文增加页内目录。移动端保持单列和可关闭导航。
- 操作页遵循“开始前准备什么、执行什么、看到什么、下一步是什么”的顺序。命令与示例输出分开，复制按钮只复制命令。
- 报错说明连接到具体恢复步骤；高级配置和开发验证不打断首次计算路线。
- 科学边界集中说明，并在会影响实际操作的位置保留简短提醒；不暗示高 R² 等于科学正确。
- 使用克制的中性色与强调色、清晰字号和行距、可见键盘焦点；不增加追踪服务、远程字体或大型前端依赖。

## 程序与兼容性

只修复可复现的使用障碍。每个行为修改先补回归测试，维持 CLI 参数、菜单编号和已有配置兼容。任何影响提交的修改必须验证不重复提交、仍需确认以及未知状态保护。无证据的偏好不作为程序缺陷处理。

## 两轮以上验收

第一轮分别审查 CLI 用户路径与文档表达；实现后由独立审查者再次检查代码和用户步骤。主线程负责页面实现、集成与最终验收。

验收包括完整单元测试、文档严格构建、链接和锚点、离线示例、安装包命令，以及桌面和移动浏览器的搜索、导航、复制、图片和溢出检查。发布后核对线上构建提交与程序 main 一致。

## 发布边界

本轮不声称真实 HPC 或新科学体系已经验证。仅在测试和审查通过后更新 main 与在线手册；保留现有开发版身份与明确的兼容性说明。
