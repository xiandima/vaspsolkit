VASPsolKit 用户手册

0.4.0 开发版 · Linux / SLURM · 中文手册

版本提示：本手册对应 0.4.0 开发快照，部分功能尚未合入 GitHub main。安装前请核对版本说明。

从一个中性结构开始，完成输入准备、任务提交、五点电荷扫描和 E-U 分析。

这是一份面向计算使用者的手册。你不需要预先算好中性参考，也不需要先学习整个命令列表。

01准备输入02中性计算03五点扫描04检查与分析

从这里开始

第一次使用： 先完成安装，再按第一次计算走一遍。 已有计算目录的用户，可以直接打开菜单，查看当前阶段：

cd "/path/to/my-case"
vaspsolkit

输入 02 执行当前推荐的一步；03 查看完整状态；00 退出并保留任务记录。 提交仍需明确确认，退出终端不会取消服务器作业。

反应分析

计算前确认

  • 计算方式： 固定 NELECT 扫描后建立 E-U 关系，不是运行中自动调节电子数的恒电势求解器。

  • 输入： 每个体系一个独立目录；VASP/VASPsol、合法赝势和本机运行脚本由你提供。

  • 默认初猜： 中性点从全新密度开始，扫描点使用中性 CHGCAR，不读取 WAVECAR。

  • 拟合： 五点包含唯一中性点，不静默删点；结果还需审查结构、磁态和电势参考。

当前为开发版文档。真实服务器环境与科学方法的验收范围见兼容性说明和 计算约定。
