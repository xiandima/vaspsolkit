## 验证与剩余边界

新增回归覆盖 reaction 实际豁免、来源缺失但区间已知、未知区间报告、非法区间、
中性点显式排除、公共脚本唯一启动、README 命令解析与相对文档链接。
完整测试在临时 Case 和隔离活动目录中运行，结果为 **511 passed**；脚本 bash 语法检查、
Python 编译检查通过，当前工作树成功构建 `vaspsolkit-0.4.0-py3-none-any.whl`。
这些验证不执行 VASP，不代表该版本已提交或发布。
本轮未新增模型校准、自动真空平台识别、输入文件物理指纹或真实 SLURM 环境验收。

仍须注意：reaction 的范围检查针对请求网格，不传播 E(system, U+offset) 的参数变换；
应使用 E(system, U) 并在公共采样范围内组合。普通 postprocess 的未知质量标志默认值、
人工方法标识和版本分支选择仍要求人工审核；文档不将这些限制描述为已经解决。

历史科学计算及论文图不属于本次验收，本次修正文档不能作为它们重新通过五点拟合或
中性点物理问题已解决的证据。发布需由维护者单独审阅并授权。
