# 第一次计算

这一章从一个新的 Case 开始，使用交互菜单完成默认的“中性优化 + 五点扫描”。
真实计算需要等待集群任务完成；不要把各阶段当作一段可以连续执行到底的脚本。

## 1. 准备目录

每个体系单独建目录，不要在程序源码目录计算。

```text
my-case/
├── POSCAR
├── INCAR
├── POTCAR
├── KPOINTS
└── vasp.slurm
```

INCAR 已有有效 KSPACING 时可省略 KPOINTS。缺 INCAR 或 POTCAR 时，准备自己的模板和合法赝势库，
按[输入准备](inputs.md)补齐；不要求已有 OUTCAR、WAVECAR 或收敛参考计算。

## 2. 打开并初始化

```bash
cd "/path/to/my-case"
vaspsolkit
```

选择 `11` 初始化。核对自己的 SHE 参考值与来源、调度器、提交脚本和 INCAR 关键参数，
确认后写入配置。已有 Case 不要再次初始化。

```text
11  初始化 Case 配置
20  准备中性结构优化
21  提交中性任务
22  检查中性任务与收敛
```

通常也可以反复选择 `02`，让程序根据当前状态推荐下一步。

## 3. 提交中性任务

选择 `20` 准备，核对准备后的 INCAR，再选 `21`。提交资源界面可选择：

- 使用已有配置。
- 选择当前服务器的分区，再由 SLURM 自动分配节点。
- 先选分区，再指定该分区的具体节点。

确认任务数、时限和脚本后，输入 `SUBMIT` 才提交。默认的 compute、96 tasks 和 72 小时时限
不是所有服务器都适用；调整方式见[服务器配置](CLUSTER_CONFIGURATION.md)。

提交后记下 Job ID。可以选 `00` 退出，之后回到同一目录运行 `vaspsolkit` 继续。

## 4. 等待并检查中性点

选 `40` 查看已记录任务的状态，结束后选 `22` 检查收敛。需要正常、完整且通过检查的
OUTCAR、CONTCAR、CHGCAR、LOCPOT。队列中的 COMPLETED 不等于计算已经收敛。

若显示 UNKNOWN，先恢复队列查询并核对原 Job ID，不要直接重提。失败处理见[检查与恢复](recovery.md)。

## 5. 准备和提交五点

中性点通过后，依次选：

```text
30  准备带电点目录
31  检查带电点输入
32  选择并提交带电点
```

默认电子数偏移为 `[-1.0, -0.5, 0.0, 0.5, 1.0]`，目录 `3` 是独立的中性扫描点。
根目录中性准备任务不替代它，所以默认总计是 **1 + 5 个任务**。

设置了 max_inflight 后，后续批次需要回来再次选择提交。程序不会在退出后自动补交。

## 6. 查看质量与结果

五点结束后，按以下顺序操作：

| 菜单 | 检查内容 |
| --- | --- |
| `50` 收敛检查 | 每个点的输出、错误与收敛情况 |
| `60` 收集结果 | 生成原始汇总表 |
| `61` 结果审计 | 查看异常点和重算建议 |
| `62` 后处理 | 生成五点 E-U 图、曲线数据和报告 |

主要结果位于 `results/` 和 `results/eu/`。先核对原始五点和详细审计，再解读拟合系数。
[下一章：E-U 结果与示例](results.md) 展示每个文件的用途，并提供一个不需要 VASP 的合成演示。
