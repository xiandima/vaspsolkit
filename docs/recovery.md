# 检查与恢复

先查清状态和输出，再决定是否修复。保留 Job ID 和旧输出，不通过删除状态文件强制重新提交。

```{warning}
UNKNOWN 不表示任务已失败或未提交。队列查询恢复并核对原 Job ID 前，不取消、不重提，
也不删除提交记录。退出菜单只结束查看，不会取消服务器上的作业。
```
